Combine Into One FAQ Page

Turn the Weddings and Events menus into a single FAQ page, with a section for each dropdown item and a question you can open and close inside each one.

Why It Matters

As we discussed in our last meeting, visitors should not have to dig through two menus to get answers. One FAQ page puts everything in one place and is easier to keep up to date.

Once Reagan finishes the brand voice questionnaire, writing the answers for this page will be quick.

Sections on the New Page

Each item in the current dropdown menus becomes its own section:

From Weddings
  • U.S. Weddings
  • Charleston
  • Kiawah Island
  • Italy
  • All Weddings
From Events
  • Event Planning
  • Event Design
  • Brand Events
  • Corporate Events
  • Private Events

How To Do It

Before you start: do not delete any of the current Weddings or Events pages. Some of them already bring in visitors from Google. The Kiawah Island page had 31 clicks in the last three months. If a page ever does need to go, set up a redirect first. The steps are in action item 02.

  1. Create the page In Squarespace, open Pages. Click the + next to Not Linked, then choose a blank page. Name it FAQ. Keeping it under Not Linked hides it from visitors while you work.
  2. Add a section for each topic Click Edit on the page, then Add Section. Add a text block with the topic name as a heading, like "Charleston Weddings." Repeat for each topic in the list above.
  3. Add the questions Inside a section, click Add Block and choose Accordion. For each question, type the question in the title field and the answer in the description field. Visitors will click a question to see its answer.
  4. Set the page address and search details Hover over the FAQ page in the Pages list and click the gear icon. On the General tab, set the URL to /faq. On the SEO tab, add a short title and description. Action item 02 explains how to write those.
  5. Add it to the menu When the page is ready, drag it from Not Linked up into Main Navigation. Check it on your phone as well as your computer.

Rewrite Top 5 Page Titles

More people are seeing the site on Google, but fewer are clicking. Better titles and descriptions fix that without changing the pages themselves. Low risk and the fastest win.

Why It Matters

The title and short description are the first things people see in Google results. When a page shows up a lot but gets few clicks, the title and description are the problem, not the ranking. The homepage alone dropped 27% in clicks.

We keep the same page addresses and the same page text. Only the title and description change.

There Are Two Cooper Guides

Two Cooper guides live at nearly identical addresses. One ends in "anchor" and one ends in "address." They are competing with each other, splitting 97 clicks and 19 clicks. Check whether one should redirect to the other before launch. Steps are below.

The Brand Name Shows Up Twice

Journal post titles currently end with the brand name twice, because Squarespace adds "REAGAN EVENTS" to every title automatically. For example, the Dunlin guide shows up in Google as:

The Dunlin Wedding Guide | Johns Island | Reagan Events — REAGAN EVENTS

That wastes space Google would otherwise use for words people are searching for.

How To Write a Good Title and Description

Titles
  • Keep it to about 55 characters. Google cuts off anything longer.
  • Start with the words people search for, like the venue name, city, and "wedding."
  • Say the brand name once at most, at the end.
  • Every page gets its own title. No two pages should match.
Descriptions
  • Keep it to about 150 characters.
  • Write one or two plain sentences about what the reader gets from the page.
  • Give them a reason to click, like insider venue notes or planning tips.

How To Do It

Squarespace moves its menus around from time to time. If something below looks different, search the setting name at support.squarespace.com.

Fix the Repeated Brand Name (One Time)
  1. Open the search appearance settings In Squarespace, go to Marketing, then SEO, then Search Appearance.
  2. Change the format for collection items Journal posts count as collection items. Change their title format so the site name is not added a second time. Setting it to just %i uses each post's own title as written.
  3. Save Click Save. Then make sure each new journal title you write ends with "Reagan Events" only if you want the brand included.
Update the Homepage and Team Page
  1. Open the page settings Go to Pages. Hover over the page and click the gear icon.
  2. Go to the SEO tab Click SEO. Type the new title in SEO Title and the new description in SEO Description. The preview shows roughly how it will look on Google.
  3. Save Click Save. Do not change the URL field.
Update the Journal Guides

This covers The Dunlin, Santa Barbara, and The Cooper guides.

  1. Open the journal Go to Pages and click the journal page. You will see a list of posts.
  2. Open the post settings Hover over the post, click the ... menu, and choose Settings.
  3. Update the SEO tab Click SEO, add the new title and description, and click Save. Leave the post URL alone.
Sort Out the Two Cooper Guides
  1. Compare the two posts Open both guides side by side:
    • /wedding-planning-journal/the-cooper-wedding-guide-charlestons-new-waterfront-anchor (97 clicks)
    • /wedding-planning-journal/the-cooper-wedding-guide-charlestons-new-waterfront-address (19 clicks)
    If they cover the same thing, keep the "anchor" one, since it gets more clicks. Copy anything useful from the "address" post into the "anchor" post first.
  2. Take the extra post down without deleting it In the journal, open the "address" post's settings and change it from Published to Draft. The redirect in the next step only works when nothing is live at the old address.

Paste this on its own line, then click Save: /wedding-planning-journal/the-cooper-wedding-guide-charlestons-new-waterfront-address -> /wedding-planning-journal/the-cooper-wedding-guide-charlestons-new-waterfront-anchor 301 The "301" tells Google the move is permanent, so the old page's value passes to the one you kept.
  4. Test it Open the old "address" link in a private browser window. It should land on the "anchor" guide.

Fix Image Names and Alt Text

Name images clearly and describe them in plain words so Google can show them in image search. Brooke and Rob can take this on as their first task.

Why It Matters

Google Image search brought in only 16 clicks in total. For a business built on beautiful photos, that is almost nothing. Google cannot see a photo. It reads the file name and the alt text to understand what is in it.

Alt text is a short written description attached to an image. It also helps people who use screen readers.

Writing Alt Text

Alt text is one plain sentence describing what the image shows. Write it the way you would describe the photo to someone on the phone.

Cover three things when they apply: what it shows, where it is, and what kind of event it was.

The Rules
  • One sentence. Roughly six to fifteen words.
  • Sentence case. No need for a period at the end.
  • Do not start with "image of" or "photo of." That is already implied.
  • No client names. Use the venue, the city, or the type of event.
  • Never repeat the same alt text on two different images.
  • Purely decorative images, like a texture or a divider, can be left blank on purpose.
Images Already on the Site

Older images with messy file names can stay as they are. Fix them by adding alt text instead.

Do not delete and re-upload an old image just to rename it. That breaks the existing link to the image and can cost the page search visibility it has already earned.

Start with the pages that matter most, in this order:

  1. Homepage
  2. Portfolio and featured events
  3. Service pages
  4. Destination and location pages
  5. Blog posts

Image Naming System

Name every new image before it goes onto the site. Use this pattern:

venue-city-event-type-detail.jpg

Not every image needs all four parts. Use what is true and skip the rest.

The Formatting Rules
  • All lowercase.
  • Hyphens between words, never underscores or spaces.
  • No dates, photographer initials, or version numbers.
  • No client last names. Use the venue or the city instead.
  • Three to six words is the sweet spot.
  • Describe what is actually in the frame. Do not stack keywords.

How To Do It in Squarespace

New Images
  1. Rename the file on your computer first Squarespace keeps the file name you upload, so rename it before it goes on the site. On a Mac, click the file once, press Return, and type the new name. On Windows, right-click the file and choose Rename.
  2. Check the file size On a Mac, right-click the file and choose Get Info. On Windows, right-click and choose Properties. If it is over 500 KB, shrink it with a free tool like TinyJPG before uploading.
  3. Upload and add alt text Upload the image as usual. Then click the image on the page, click the pencil or gear icon, and type your sentence into the Alt Text field. Click Save on the page when you are done.
Images Already on the Site
  1. Open the page in edit mode Go to Pages, open the page, and click Edit. Work through the pages in the order listed above.
  2. Add alt text to each image Click each image, then the pencil or gear icon, and fill in the Alt Text field. For images in a gallery, open the gallery and do this for each photo.
  3. Save the page Click Save before moving on to the next page. Leave the file names as they are.

Before You Upload

  • File is named using the pattern, all lowercase with hyphens.
  • No client names anywhere in the file name or alt text.
  • Image is compressed. Aim for under 500 KB for most photos.
  • Alt text is written and describes what is actually in the frame.
  • Alt text is not a duplicate of another image on the same page.
  • The name and the alt text describe the same picture.
